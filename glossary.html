Glossary for beginners

Understand the words.
Understand the math.

This page gives you plain-language meanings of the most important words you will meet in the labs. Read a definition, then connect it to a concrete example.

Tip: search by idea, not only by the exact term.

Vector

building block

A vector is an ordered collection of numbers. It can describe a point, a direction, a velocity, a preference profile, or a signal.

In simple words: a vector is a mathematical way of packaging information with position and order.
Example: [3, 1] can mean “3 steps right and 1 step up.”

Matrix

control panel

A matrix is a rectangular table of numbers. It can store data, encode relationships, or act like a machine that transforms vectors.

In simple words: a matrix is often a compact recipe telling the system what to do.
Example: a 2×2 matrix can rotate, stretch, reflect, or shear points in the plane.

Linear Transformation

math machine

A linear transformation is a rule that takes vectors as input and returns vectors as output while preserving addition and scaling.

In simple words: if you understand what the machine does to a few basic directions, you can predict what it does everywhere.
Example: rotate every point by 90° or stretch the x-direction by a factor of 2.

Basis

reference system

A basis is a minimal set of vectors from which every vector in the space can be built uniquely.

In simple words: a basis is a set of basic directions powerful enough to describe the whole space.
Example: in the plane, the vectors (1,0) and (0,1) form the standard basis.

Span

what you can reach

The span of a set of vectors is the set of all linear combinations of those vectors.

In simple words: span tells you all the places you can reach by combining some chosen directions.
Example: the span of (1,0) and (0,1) is the entire plane.

Linear Independence

no redundancy

Vectors are linearly independent if none of them can be created from the others.

In simple words: every vector in the set contributes something genuinely new.
Example: (1,0) and (0,1) are independent, but (1,1) and (2,2) are not.

Rank

amount of information

The rank of a matrix tells you how many independent rows or columns it truly contains.

In simple words: rank measures how much non-repeated information the matrix has.
Example: if one row is just a multiple of another, it does not increase the rank.

Eigenvector & Eigenvalue

special directions

An eigenvector is a direction that stays on the same line after transformation. The eigenvalue tells how much that direction is stretched, shrunk, or flipped.

In simple words: some directions are “special” because the machine only scales them.
Example: PageRank uses an eigenvector to describe long-term importance of webpages.

Dot Product / Inner Product

measure of alignment

The dot product combines two vectors into a single number. It measures alignment, overlap, or similarity.

In simple words: the larger the overlap, the larger the dot product.
Example: recommendation systems use dot products to score how well a title matches a user.

Gradient

direction of steepest change

The gradient points in the direction where a function increases the fastest.

In simple words: the gradient is the hill-climbing arrow of a function.
Example: gradient descent moves in the opposite direction to reduce loss.

Gradient Descent

learning by correction

Gradient descent is an optimization method that repeatedly updates parameters in order to reduce error.

In simple words: take a small step downhill, measure again, and repeat.
Example: θ ← θ − η∇L is the core rule used in machine learning.

Projection

best shadow

A projection takes a point and places it onto a line or subspace in the nearest possible way.

In simple words: projection is the “shadow” of a point on a chosen direction or space.
Example: least squares finds the projection of data onto a model space.

How to use this page

Open a lab, notice a word you do not fully understand, then return here. Read the simple explanation first, then the formal meaning, and finally the example.
