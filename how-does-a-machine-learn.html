The loss function

Square each error (so positive and negative errors can't cancel), average them:

L(w,b) = (1/n) · Σ (yᵢ − (w·xᵢ + b))²

The line depends on (w, b) → so the loss depends on (w, b): L = L(w,b). Our whole job is to make this number small.

Why square the error? Compare: Σeᵢ lets +5 and −5 cancel (looks perfect!); Σ|eᵢ| never cancels but has a sharp corner; Σeᵢ² never cancels, is smooth, and is easy to differentiate. Squared error is one convenient smooth loss — not the only possible one.

The math behind it all

Everything so far in one place: the matrix form, the closed-form answer, and a look ahead at harder optimization landscapes.

Matrix form

Stack the data: X has a column of 1s (for b) and the x values. θ = [b, w].

X = [[1,x₁],[1,x₂],…],   θ = [b, w]
ŷ = X·θ
L(θ) = (1/n) · ‖y − X·θ‖²₂

Is gradient descent the only way?

For linear regression there is a closed-form least-squares solution (when XᵀX is invertible):

θ̂ = (XᵀX)⁻¹Xᵀy

Local vs global minima (general example)

The linear-regression MSE surface is convex — one valley, no traps. Real loss surfaces can have hills and valleys. This is a general example, not linear regression.

Saddle point: f(x,y) = x² − y²

At the origin, ∇f = 0 — but it's neither a max nor a min! Gradient zero does not always mean minimum.

Constrained optimization (look ahead)

What if the best point is NOT allowed? Minimize (x−1.2)² + (y+0.8)² but stay on the unit circle x²+y²=1. Drag θ (the angle) around the circle.

Lagrange multipliers — coming later: at the optimum, ∇f is parallel to ∇g: ∇f = λ·∇g.

Noise & outliers

More noise → perfect prediction becomes impossible → the minimum achievable loss rises. Squared error gives large errors (outliers) a lot of influence.

Quick check

Test your understanding

What is the role of the loss function?

It measures how wrong the model is.

Why do we move opposite to the gradient?

Because the gradient points uphill; moving opposite to it takes us downhill and reduces loss.

True or false: one step of gradient descent always gives the final answer.

False — learning is iterative and usually needs many updates.

Common mistakes students make

  • Confusing the model output with the loss value.
  • Choosing a step size that is too large and overshoots.
  • Thinking learning is magic instead of repeated numerical correction.
