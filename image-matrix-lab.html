What exactly are we transforming?

Two very different things live inside an image. Keeping them apart is the key idea of this lab.

1 · The image matrix stores pixel values

It answers: “How bright / what colour is each pixel?” Rotating it with a 2×2 matrix is not how images rotate.

2 · The transformation matrix acts on coordinates

It answers: “Where does each pixel move to?” A geometric matrix like rotation acts on the coordinate vector p, never on the intensity matrix directly.

Intensity matrix = what you see. Transformation matrix = where each point goes.

What happened to AREA?

Unit square (area 1) → parallelogram (area |det A|).

det(A) = 2 ⇒ the area doubles. det(A) = 0 ⇒ the square collapses into a line — information about one spatial dimension has been lost.

What if we perform TWO transformations?

First p′ = A·p, then p″ = B·p′. Together: p″ = (B·A)·p — one matrix does the work of two.

AB ≠ BA ! ROTATE → STRETCH is not the same as STRETCH → ROTATE. Order matters — that's why matrix multiplication is defined the way it is.

Undo, using Mathematics

If p′ = A·p, then p = A⁻¹·p′. Apply the inverse and watch the image return.

This transformation cannot be perfectly reversed. det(A) = 0 — the square collapsed flat, so A⁻¹ does not exist.

🧭 Why are we learning this?📘 Open the glossary

What you just discovered

  • An image can be treated as a grid of numbers and points.
  • A matrix acts like a machine that transforms every point in a consistent way.
  • Knowing what the transformation does to the basis directions helps predict what happens everywhere.

Why this matters

  • Computer graphics and animation
  • Computer vision and image processing
  • Augmented reality and game engines
Quick check

Test your understanding

True or false: every matrix transformation preserves distances.

False — stretching and shearing do not preserve distances.

Why are the vectors (1,0) and (0,1) so important?

They are the standard basis vectors; once you know how they move, you can describe how all other points move.

What does the determinant tell you in this context?

It tells you the area scaling factor and whether orientation flips.

Common mistakes students make

  • Thinking every transformation is a rotation or reflection.
  • Forgetting that order matters when composing transformations.
  • Assuming a transformed image must keep the same size or shape.
